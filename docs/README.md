# Documentation assets

Everything here is meant to be opened directly — no build step, no server.

## `images/`

Regenerated by `python -m src.visualize`; nothing here is hand-drawn.

| File | Produced from | What it shows |
| :-- | :-- | :-- |
| `training_curves.png` | `outputs/resnet18-64/history.csv` | Accuracy, loss and learning rate across the 100-epoch run; the dotted line is where the backbone was unfrozen |
| `confusion_matrix.png` | `outputs/eval/confusion.json` | 102×102 counts on the validation split, log colour scale |
| `sample_predictions.png` | the checkpoint + `datasets/flowers/valid` | Eight random validation images with the model's top-1 and probability |
| `class_distribution.png` | `datasets/flowers/train` | How imbalanced the training split is |
| `demo_app.png` | the running Flask app | Screenshot of the demo with a real prediction |

## Where the numbers come from

`outputs/eval/metrics.json` is the source of every accuracy figure in the README.
Regenerate it with:

```bash
python -m src.evaluate --output-dir outputs/eval
```

The training history in `outputs/resnet18-64/history.csv` is not produced by the
current trainer — the published checkpoint predates it. It is restated from the
raw logs in `legacy/` by `scripts/import_training_log.py`, which keeps the two
curves continuous across the stage boundary.
